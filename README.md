# Tkinter con POO - Gestión de Tareas

Implementando arquitectura de separación por capas (`Repository -> Services -> UI`).

## Arrancar la aplicación

```bash
python -B main.py
```

## Estructura del proyecto

```
proyecto_tareas/
│
├── repositories/
│   └── task_repository.py
│
├── services/
│   └── task_service.py
│
├── models/
│   └── task.py
│
├── ui/
│   └── app_window.py
│
└── main.py
```
